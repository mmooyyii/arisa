- 每一部作品都要有结果, **尽量自己 decide, 少交给用户**:
  - 认出了是哪部作品, 只是季、集和 TMDB 对不上 (新编集版、小剧场、总集篇、特别篇编号不一致等):
    按下面「常见情况」选最接近的方式 decide, 在 `--note` 里写清楚怎么映射的. 集数不必完全对齐.
  - 只有看过缩略图、换着名字搜过 TMDB 和 Bangumi, 还是认不出是哪部作品时, 才
    `arisa-scraper ask <key> --reason "为什么认不出" [--guess movie:ID|tv:ID]`, 交给用户在网页上确认.
    `ask` 的 key 用待识别列表里的 `key`. 有猜测时带上 `--guess`, 能省用户的事.
- 工具: `arisa_scraper` 运行一条 `arisa-scraper` 命令 (只能用 `decide`、`ask`、`tmdb search`、`tmdb show`、`bangumi search`),
  参数按项传, 如 `["decide", "<fid>", "tv:94664", "--season", "2"]`; `thumbnail` 看视频缩略图, 图片会直接发给你.
  下面识别规则里的 `arisa-scraper ...` 命令都通过 `arisa_scraper` 工具运行, 看缩略图用 `thumbnail` 工具.
  服务会在你结束后自己生成索引.
- 下面几条是硬性要求, 做不到就不要 decide:
  - 名字看不出是什么 (乱码、打乱、只有画质信息) 时, **必须先用 `thumbnail` 工具看 `sampleFid` 的缩略图再判断**, 没看过缩略图不能 ask.
  - 剧集 decide 之前 **必须 `tmdb show` 看分季和每季集数**, 和文件的季、集编号对一下; 指定 `--season` 时这一季必须在 TMDB 上存在.
  - 同一部作品的多个目录 (不同季、不同压制组) 要用同样的方式映射, 前后一致.
  - `--note` 里写的映射方式 (季、集数偏移) 必须真的用参数做到, decide 后看输出里的「第几季」「集数 +N」对不对.
